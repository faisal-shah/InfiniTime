# Family firmware rewrite planning package

This directory is proposal-only. No family firmware implementation or flashable
artifact has been created on `family-rewrite`.

1. Read [`PROPOSAL.md`](PROPOSAL.md) for the incident-based architecture,
   budgets, and staged delivery plan.
2. Review [`DECISIONS.md`](DECISIONS.md) and accept or change the recommended
   product behavior.
3. Use [`REQUIREMENTS.md`](REQUIREMENTS.md) as the acceptance contract after
   those decisions are resolved.

Implementation must not begin until the blocking decision rows are reconciled
into the proposal and requirements.
